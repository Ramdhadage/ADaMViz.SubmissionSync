Feature 09 · Current implementation

Human review decisions

Two independent role approvals complete review. A rejection closes the revision to further review decisions.

The middle state represents pending approval. Additional approvals that cover only one role leave it Verified. New decisions require a fresh version; identical command retries do not add records.

Inter and Geist Mono load from Google Fonts; offline fallbacks are Segoe UI/Arial and Consolas/monospace. Read the feature documentation.
