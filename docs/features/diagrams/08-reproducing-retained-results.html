ADaMViz SubmissionSync · Feature 08

Reproducing retained results

A separately requested replay reads retained inputs and compares identities. The default runner executes in the current R process. Replay does not change review status or control the normal export path.

An environment mismatch still fails replay. The diagram combines data and script retrieval in one step; reconstruction rules and fingerprint limits are detailed in the feature documentation.

Application palette: navy #0B3C5D and slate #5B6770. Text uses Inter with Segoe UI and Arial fallbacks; technical labels use Geist Mono with Consolas fallback. Font availability can change rendering.
